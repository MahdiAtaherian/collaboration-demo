# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## How to contribute
1. Open an issue in the original repository to describe the proposed change and why it is needed.
2. Fork the repository and clone your fork.
3. Create a separate branch for the issue.
4. Make the changes and commit them with a clear message.
5. Push the branch to your fork.
6. Open a pull request targeting the main branch of the original repository and link the related issue.
7. Address reviewer feedback by adding commits to the same branch.
8. Wait for approval and successful CI checks before the maintainer merges the pull request.

## CI scope
The current CI workflow only prints a message. It does not run automated tests.
